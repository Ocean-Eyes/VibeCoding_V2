# 방문자 통계

메인 화면 왼쪽 사이드에 작은 통계로 전체 이용자 수와 국가별 국기·방문자 수를 세로로 표시한다. 국가가 많으면 목록 안에서 스크롤한다. 사이트 어느 주소로 처음 들어와도 집계한다. 기존 무료 Redis를 사용하며 유료 서비스나 자동 업그레이드를 추가하지 않는다.

- 배포 이후 처음 방문한 **브라우저**를 1회 집계한다. 로그인 기반 실제 사람 수가 아니다. 다른 기기·브라우저·시크릿 창이나 브라우저 저장소 삭제는 새 방문자가 될 수 있다.
- 과거 Vercel Analytics 수치를 합산하지 않는다. 공개 통계는 새 집계 시작 이후의 숫자다.
- 최초 방문 국가를 Vercel의 `x-vercel-ip-country`로 결정한다. VPN 등의 영향이 있을 수 있으며, 알 수 없는 국가는 별도로 표시한다. 국가 헤더 기준: <https://vercel.com/docs/headers/request-headers>.
- UUID를 브라우저에 저장하고, 서버에는 HMAC 해시와 국가 코드만 저장한다. IP 원문을 저장하지 않으며 IP의 HMAC은 시간당 신규 등록 제한용으로 1시간만 보관한다. 알려진 봇·자동화·로컬/미리보기 페이지는 자동 집계하지 않는다. 인증이 없는 통계로 부정 집계를 완전히 방지하지는 못한다.
- Redis 키는 `just-judo:visitors:v1:*`를 사용한다. 중복 확인·추가·제외·국가 합계 변경은 Lua로 원자적으로 처리한다. 전체 수는 국가별 합계다. 재방문은 클라이언트에서 쓰기를 생략하며 공개 읽기는 CDN에서 60초 캐시한다. 무료 한도에 도달하거나 오류가 발생하면 숫자를 조작하지 않고 오류 상태를 표시한다.
- 국기는 flag-icons 7.6.0의 SVG를 `assets/flags/`에서 직접 제공하여 Windows에서도 표시한다. MIT 라이선스를 함께 보관한다. 알 수 없는 코드는 문자로 표시하며 외부 이미지 서버에 의존하지 않는다.

## 운영자 방문 제외

사용하는 각 브라우저에서 **https://justjudo.app/?exclude_visits=1** 을 한 번 열거나 메인 통계의 **집계 설정 → 내 방문 제외**를 누른다. 설정은 `just-judo-visitor-excluded`에 저장된다. 이 브라우저의 기존 공개 통계 1건도 차감하고 이후 재방문을 제외한다. 다른 방문자가 보는 캐시에는 반영까지 최대 3분 걸릴 수 있다.

제외 중 버튼을 다시 누르면 해제된다. 저장소가 차단되면 집계하지 않으며, 제외 저장/서버 반영 실패 시 오류를 표시한다. 새로고침하면 미완료 반영을 재시도한다. 기기·브라우저마다 별도 설정이 필요하며, 저장소 삭제 전의 다른 익명 ID를 소급해서 식별할 수는 없다.

기존 Vercel Web Analytics의 `beforeSend`에도 동일한 설정을 적용하여 이후 이벤트 전송을 제외한다. Vercel에 이미 기록된 과거 이벤트까지 삭제하지는 않는다.

## 검증

`node --test tests/visitors.test.mjs` 및 `node scripts/browser-visitors.cjs <playwright 경로>`.
브라우저 검증은 API를 모의 처리하여 실제 집계를 늘리지 않는다. 서버 Lua는 별도의 임시 Redis 키로 실행해 중복·동시 요청·제외 이후 재시도·해제를 확인한다.
