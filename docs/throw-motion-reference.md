## 현재 밭다리 연습 모드

사용자의 새 요청에 따라 밭다리만 3단계 정적 자세 미션으로 전환했다. ① 손을 당기고 왼발 딛기 ② 오른발 앞으로 높이 들기 ③ 상체를 숙이고 오른발 뒤로 들기. 기존 검증된 밭다리 동작의 1.45 / 2.0 / 2.60 시점에서 금색 목표 전신을 추출하며, 사용자 골반 위치·몸 크기에 정렬한다. 카메라 영상은 거울로 표시하고 목표 좌우도 같은 기준으로 표시한다. 실제 상대 접촉·힘·유도 기술 효과를 판정하지 않는다.

MediaPipe 전신 관절을 비스듬한 시점의 목표와 비교한다. 허용 범위 안에서 각 자세를 1초 유지하면 Perfect 후 다음 단계로 이동한다. 왼발 지지·오른발 위치·상체 기울기·양손 위치를 별도로 확인하며, 발이 가려지거나 추적이 끊기면 유지 시간이 초기화된다. 안다리·업어치기는 기존 연속 시연을 유지한다. 아래 단계 제거 기록은 이전 동작 방식의 이력이다.

검증: `tests/osoto-practice.test.mjs`, `scripts/browser-osoto.cjs`. 브라우저 검사는 합성 관절을 사용하며 실제 웹캠 인식률 검증은 별도다.

# 메치기본 시연 기준

오른손잡이 기준의 혼자 따라 하는 입문 시연이다. 카메라 화면을 거울처럼 반전하지 않는다. 흰 도복은 거는 사람(tori), 푸른 도복은 받는 사람(uke)이다. 시연은 하나의 연속 동작으로 재생한다. 원본의 동작에 기울이기·지읏기·걸기 순서를 임의로 부여하지 않는다. 단계 버튼·단계별 설명·체크·자동 정지를 제공하지 않으며, 전체 재생·일시정지·탐색·반복을 제공한다. 실사 영상을 제품 시연 대신 넣지 않는다.

## 직접 확인한 원본

2026-10-29 IJF 기술 페이지의 Kodokan / IJF Academy 정형 시연을 추출하여 확인했다. 각 페이지의 첫 번째 영상은 경기 모음이고 두 번째 영상이 아래 정형 시연이다. 경기 변형을 정형 시연에 섞지 않는다.

| 기술 | 원본 | 확인한 사건 |
| --- | --- | --- |
| 밭다리 후리기 | [O-soto-gari](https://judo.ijf.org/techniques/O-soto-gari) | 11.0–11.5초 잡기·진입, 11.75초 후릴 다리 들어 올림, 12.0–12.75초 바깥 후리기·상체 전진 |
| 안다리 후리기 | [O-uchi-gari](https://judo.ijf.org/techniques/O-uchi-gari) | 11.5–12.0초 두 발 사이 진입, 12.25–12.75초 상대 다리 안쪽 후리기 |
| 한팔 업어치기 | [Ippon-seoi-nage](https://judo.ijf.org/techniques/Ippon-seoi-nage) | 15.0–15.75초 소매 당김·회전, 16.0초 팔 끼우기·무릎 굽힘, 16.25–17.75초 다리 펴기·어깨 너머 회전 |

업어치기 영상의 도입 타이틀에는 다른 기술명이 표시되지만, 본문 시연과 하단 자막은 한팔 업어치기다. 제목만으로 판단하지 않고 위 구간의 실제 동작과 IJF 기술 설명을 함께 확인했다.

추출 자료는 `.test-output/throws/ref-*-*.jpg`, 사건별 시트는 `events-*.jpg`이며 저장소에 커밋하지 않는다. 원본은 참고 링크로만 제공하며 재배포하지 않는다.

## 좌표와 접촉 계획

- +Y 위, 거는 사람 준비 자세의 앞 +Z, 신체의 오른쪽 -X. 정면 카메라에서 얼굴을 볼 때 신체의 오른쪽은 화면 왼쪽에 놓인다. 받는 사람은 -Z를 향하므로 그 사람의 오른쪽은 +X다. 모든 회전에서 `right = cross(forward, up)`을 유지한다.
- 웹의 오른손잡이 구현 목표(원본 시연자의 좌우 판정과 구분): 밭다리의 왼발 지지·오른다리 바깥 후리기, 안다리의 오른발 진입·왼발 지지·오른다리 안쪽 원호, 업어치기의 왼쪽 회전·무릎 굽힘·등 밀착·오른팔 끼우기.
- 웹의 오른손잡이 잡기 목표: 왼손의 소매 제어를 유지한다. 업어치기의 오른손은 깃에서 풀려 오른겨드랑이 아래로 이동한다. 받는 사람의 왼팔은 넘어질 때 풀린다.
- 구현상 추론: 카메라에 가려진 관절의 깊이, 정확한 손가락·옷감 접촉점, 모든 중간 프레임의 3D 위치. 고정 길이 관절 모델과 연속 보간으로 구성하며 모션 캡처나 접촉 물리 시뮬레이션으로 표기하지 않는다.
- 걸기 방향과 거는 사람의 준비·지지·회전 동작이 학습 대상이다. 실제 낙법의 손바닥 충격·힘·상대의 반응을 판정하는 기능은 없다.

## 2026-11-02 단계 구분 제거

사용자 지시에 따라 원본에 대응하지 않는 기울이기·지읏기·걸기 구분, 단계 설명·체크·자동 정지를 제거했다. 메인과 기술 목록, 이용 안내의 같은 순서 주장도 제거했다. 기존 11.4초의 동작 시간은 유지하고 하나의 재생 막대, 일시정지, 처음부터 재생, 전체 반복을 제공한다. 내부 키포즈의 시간 구간은 애니메이션 보간용이며 유도 동작 단계로 해석하지 않는다. 아래 과거 검증 기록의 단계 UI는 현재 제공되지 않는다.

원본 시연을 오른손잡이로 단정했던 기록도 정정했다. 원본의 좌우와 웹에서 요청받은 오른손잡이 기준은 별개다. 원본의 동작 사건을 비교할 때 오른손잡이 구현 목표를 원본에서 관찰한 사실로 바꿔 적지 않는다.

Chrome에서 세 기술을 처음부터 끝까지 재생해 기존 경계에서 멈추지 않음을 확인했다. 전체 탐색·반복, 일시정지·재개, 처음부터 재생, 0.5배속, 혼자 보기, 모바일·영문 화면 및 기존 띠·배밀기·조르기 화면 이동 검사를 통과했다.

## 2026-11-02 신체 좌우 기준 수정

이전 구현은 변수 이름을 오른손·오른발로 정해 놓고도, 얼굴을 정면으로 봤을 때 실제 왼쪽에 배치했다. 따라서 10월 31일 검증은 접촉과 관절 길이를 확인했지만 오른손잡이 여부를 올바르게 검증하지 못했다.

세 기술의 키포즈와 보정 데이터의 월드 X 좌표, 신체 좌우 축, 발 모양과 충돌 외형을 함께 수정했다. 카메라나 CSS를 반전하지 않는다. 위에서 본 발 지도는 +Z를 화면 위로, -X를 화면 오른쪽으로 투영한다. 오른손은 상대 왼깃, 왼손은 상대 오른소매를 잡으며, 후리는 다리와 업어치기에 끼우는 팔은 실제 신체의 오른쪽이다.

수정 전과 1,803개 시점을 대조해 좌우 변환 외의 위치 차이가 0이고 기존 동작 시간이 동일함을 확인했다. 신체 정면·등 방향과 회전 중의 좌우 축 검사를 추가했다. 관련 테스트 23개 통과, 기존 723개 시점의 접촉 외형 관통 검사도 유지했다. 시각 비교 자료는 `.test-output/throw-handedness/`에 보관한다.

## 2026-10-31 직접 구현 보정

강화학습 실험은 중단했으며 학습 모델이나 추정 경로를 웹 시연에 가져오지 않았다. 기존의 오른손잡이 키포즈를 직접 수정했다. 비어 있던 접촉 데이터 대신 세 기술 각각 121개 자세를 계산해 포함했다. 계산은 `node scripts/bake-throw-contact.mjs`로 재현하며, 웹 재생 중에는 관절 보간과 고정 길이 역기구학만 실행한다. 특정 기술만 재생성하려면 기술 ID를 인자로 전달한다.

- 밭다리 후리기: 끝 자세에서 왼발 지지를 유지하며 오른다리를 뒤로 높게 뻗는다. 시전자가 함께 주저앉는 학습 동작은 사용하지 않는다.
- 세 기술 공통: 왼손의 접촉을 상대 오른소매의 길이 방향 위치와 표면 두께로 계산한다. 오른손 깃 접촉은 상대 왼깃을 기준으로 계산한다. 손 좌표를 접촉 정답으로 복사하던 검사를 제거했다.
- 한팔 업어치기: 오른팔을 끼운 뒤 손을 뺄 때 상대 소매 바깥을 돌아 나온다. 머리와 상대 팔 사이의 여유를 확보한다. 가려진 이탈 경로의 깊이는 구현상 추론이다.
- 도복과 손: 연결된 깃·겹침·단·소매의 잡힌 주름, 접촉 면을 향한 손바닥, 좌우 엄지 방향을 표시한다. 소매 주름은 국소 형상이며 천의 장력 시뮬레이션은 아니다.

검증 결과: 관련 테스트 21개 통과, 빌드 성공. 그립은 1,803개 시점, 신체 겹침은 보정 프레임과 그 사이를 포함한 723개 시점에서 검사했다. 검사한 신체 외형 조각 사이의 관통은 0건이다. 이는 샘플 검사이며 모든 시각의 충돌 부재나 유도 기술의 물리적 정확성을 보증하지 않는다.

Chrome에서 세 기술의 정면·측면·입체 화면, 전체 재생·단계 정지·일시정지·혼자 보기·모바일을 확인했다. 연속 재생의 순차 캡처도 확인했다. 기존 띠·배밀기·조르기 화면으로의 이동과 브라우저 뒤로/앞으로 가기가 통과했다. 수정 전 파일과 화면, 원본 사건 비교, 연속 캡처는 커밋하지 않는 `.test-output/throws-direct/`에 보관했다. 원본과의 비교는 사건과 잡기 관계에 대한 것이며, 자세 각도·옷감·낙법을 실사와 동일하게 복원했다는 뜻은 아니다.

## 검증 범위

원본의 사건별 자세와 웹 시연을 같은 동작 사건으로 비교한다. 정면·측면에서 무릎, 지지발, 후리는 다리와 양손을 확인한다. 동작 전환의 연속성, 관절 길이, 유지 중인 그립의 연결, 바닥 아래로 내려가는 관절, 재생·정지·반복·페이지 이탈을 별도로 검사한다. 수치 테스트는 실제 유도 기술의 효과나 모든 시점의 신체 충돌 부재를 보증하지 않는다.

2026-10-29 구현 검증: 관련 테스트 17개 통과. 세 기술마다 301개 시점을 샘플링해 관절 길이, 목표점 도달, 왼손 소매 연결, 관절·머리의 바닥 여유를 검사했다. 브라우저에서 정면·측면·입체의 각 단계 0/25/50/75/100%를 캡처하고 원본의 준비·진입·걸기·종료 사건 12쌍을 비교했다. 원본과 측면 카메라의 방향이 다른 경우 인체의 좌우 이름으로 비교하며 화면을 반전하지 않는다.

단계 정지·반복·전체 연속 재생, 0.5배속, 혼자 보기, 수동 체크, 모바일·영문, 직접 주소 진입·새로고침·뒤로 가기를 확인했다. 로컬 Chrome 측정에서 연속 재생 프레임 간격 중앙값 약 16.7ms, 95백분위 약 16.8ms였으며 기기별 성능 보장은 아니다. 기존 띠·배밀기·조르기로 이동하는 회귀 검사도 통과했다. 실제 사람의 카메라 동작을 판정하는 기능은 이번 레슨 범위에 없다.
