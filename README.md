# Just Judo

[웹사이트 열기](https://ocean-eyes.github.io/VibeCoding_V2/)

설치 없이 PC/노트북 웹브라우저에서 이용하는 유도 학습 도장입니다. Yuji Boku 붓글씨 서체의 柔道·基本·固技·投技, 종이 질감, 먹선, 붉은 낙관을 사용한 두루마리 도장 UI입니다. 상품 카드 대신 과정 칸과 기술 목록을 사용합니다. 특정 단체의 공식 서비스는 아닙니다.

## 메뉴와 현재 범위

첫 화면은 **기초 → 굳히기본 → 매치기본** 순서입니다.

- 기초: 도복 입는 법, 띠 매는 법, 낙법. 예정 레슨으로 표시하며 아직 실행되지 않습니다.
- 굳히기본 / 조르기: **십자조르기, 역십자 조르기, 외십자 조르기**를 각각 선택할 수 있습니다.
- 매치기본: 다음 레슨을 위한 메뉴이며 아직 실행되지 않습니다.

조르기 기술마다 그립 개념 설명, 손바닥 방향 개념도, IJF 공식 설명·시범 링크, 그립 확인 문제, 웹캠 손 위치 예비 연습이 있습니다. 이전의 일반 팔 벌리기·V자·파워 포즈 동작은 제거했습니다.

## 미션과 기록

1. 기술을 선택하고 그립 설명을 읽습니다.
2. 방향 문제에 정답을 선택하면 10 XP를 받고 손 위치 연습이 열립니다.
3. 카메라에서 그립 준비 → 첫 손 교차 → 양손 교차 순서로 팔 위치를 따라합니다.
4. 각 단계는 팔 위치 50% 이상을 연속 3초 유지하면 통과합니다. 세 단계를 마치면 20 XP와 해당 기술의 예비 연습 완료 도장을 받습니다.
5. 기술별 XP는 최초 1회 지급하며 다시 연습해도 중복되지 않습니다. 3종 합계는 최대 90 XP입니다.

진행도는 브라우저 localStorage의 `just-judo-progress-v1`에 저장합니다. 저장이 차단되면 현재 방문 동안만 동작하며 이를 화면에 표시합니다. 가상 시범은 XP나 완료 기록에 반영하지 않습니다. 메뉴로 나갈 때 카메라와 추론 Worker를 종료합니다.

## 웹캠 판정의 범위

**웹캠은 혼자 하는 교차 팔 위치의 예비 연습을 평가합니다. 실제 유도 기술의 숙련도·효과를 판정하지 않습니다.**

세 기술의 핵심 차이는 손바닥 방향입니다. 이것은 그립 문제와 설명으로 학습하며 웹캠이 자동 판정한다고 표시하지 않습니다. 세 기술에서 공유하는 팔 위치 예비 연습은 같습니다. 깃 잡기, 압박, 상대의 자세, 실제 조르기 완성도는 판정 범위 밖입니다. 상대와의 실습은 지도자의 지도를 받으세요.

- MediaPipe Pose Landmarker와 Hand Landmarker를 별도 Worker에서 실행합니다.
- 양어깨 중점·너비·기울기를 기준으로 목표를 정렬하며 골반이 화면 밖이어도 작동합니다.
- 목표의 상완·전완 길이는 인식된 사용자의 영상 속 팔 길이에 맞춥니다.
- 팔꿈치/손목 위치 오차를 어깨 너비로 정규화하여 `100 × exp(-3.5 × 평균오차)`로 점수를 계산합니다.
- 손가락은 보조 시각화하고, 손 추적 수를 표시합니다. 손 모양 점수를 기술 정확성 점수에 합산하지 않습니다.
- 주요 관절이 가려지거나 추론 결과가 오래되면 채점을 멈춥니다.
- 신체가 인식되기 전에도 중앙 참고 가이드를 표시하되 미정렬 상태임을 명시합니다.
- 추적 오류가 나도 영상은 유지하고 오류 및 재연결 버튼을 표시합니다.

영상을 서버로 전송하거나 저장하지 않습니다. 최초 카메라 연결 시 jsDelivr의 고정 버전 `@mediapipe/tasks-vision@0.10.22-rc.20250304`와 Google Storage의 모델 파일을 다운로드합니다. 글꼴은 Google Fonts를 사용하며 실패하면 시스템 글꼴로 표시됩니다. 웹캠에는 HTTPS 또는 localhost가 필요합니다.

## 기술 참고

- [십자조르기 / Nami-juji-jime](https://judo.ijf.org/techniques/nami-juji-jime)
- [역십자 조르기 / Gyaku-juji-jime](https://judo.ijf.org/techniques/gyaku-juji-jime)
- [외십자 조르기 / Kata-juji-jime](https://judo.ijf.org/techniques/Kata-juji-jime)

## 개발과 배포

Node.js 20 이상, 별도 앱 의존성 설치 없이 실행합니다.

```sh
npm start
# http://localhost:5173
npm test
```

`main` 푸시 시 GitHub Actions가 테스트 후 HTML, dojo.css, src 모듈만 Pages에 배포합니다.

Playwright 패키지가 있는 환경에서:

```sh
node scripts/browser-dojo.cjs <Playwright 패키지 경로>
node scripts/browser-regressions.cjs <Playwright 패키지 경로>
```

`SITE_URL` 환경 변수로 배포 사이트를 검사할 수 있습니다. 도장 검사에는 메뉴·그립 정오답·저장·중복 XP 방지·가상 시범 제외·가상 카메라의 실제 모델 초기화·메뉴 복귀 시 카메라 해제·반응형 레이아웃이 포함됩니다. 미션 완료 흐름은 합성 관절을 주입하여 검증합니다. 회귀 검사는 공개 인물 사진을 영상 입력으로 사용하며 오류도 강제로 주입합니다. **이 검사는 실제 사용자가 유도 동작을 하는 웹캠 환경의 인식률 검증을 대신하지 않습니다.**
