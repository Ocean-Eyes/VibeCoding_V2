# Just Judo

PC/노트북 RGB 웹캠으로 동작하는 상체·손 동작 유도 연습 웹사이트입니다. 기존 Baseline과 독립적으로 구현했습니다. VR, MR, WebXR, 헤드셋, Depth 센서는 사용하지 않습니다.

## 웹사이트 접속

**[Just Judo 열기](https://ocean-eyes.github.io/VibeCoding_V2/)**

설치나 실행 파일 없이 PC/노트북 브라우저에서 접속하고 카메라 권한을 허용하면 됩니다. HTTPS로 제공되어 웹캠을 바로 사용할 수 있습니다.

`main`에 변경 사항을 푸시하면 GitHub Actions가 테스트를 실행하고 GitHub Pages에 자동 배포합니다. 배포 대상에는 웹 화면과 실행에 필요한 JS/CSS만 포함됩니다.

## 개발용 로컬 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
# http://localhost:5173
npm test
```

Python만 있는 경우 `python -m http.server 5173 --bind 127.0.0.1`로 실행할 수도 있습니다. 카메라는 localhost 또는 HTTPS에서만 사용할 수 있습니다. Chrome/Edge 최신 버전을 권장합니다. 파일을 더블클릭하는 `file://` 실행은 지원하지 않습니다.

## 사용

1. 카메라 연결을 누르고 브라우저 권한을 허용합니다. 처음에는 모델 다운로드가 필요합니다.
2. 밝은 곳에서 어깨, 팔꿈치, 양손이 화면에 보이도록 섭니다. 골반이 화면 밖이어도 상체를 기준으로 정렬합니다.
3. 연습 시작 후 민트색 목표와 하늘색 현재 관절을 맞춥니다. 주황색 화살표는 손목 오차 방향입니다.
4. 일치도 80% 이상을 연속 3초 유지하면 다음 동작으로 진행합니다. 인식이 끊기거나 기준 미달이면 유지 시간은 초기화됩니다.
5. 이전/다음 및 동작 카드를 통해 자유롭게 이동하거나 일시 정지할 수 있습니다. 카메라 끄기는 영상 트랙과 Worker를 모두 종료합니다.

카메라 없이 데모로 모든 UI를 확인할 수 있습니다. 데모는 합성 관절 및 가상 손 점수를 사용하며 실제 연습 완료 기록과 분리되어 있습니다. 완료 상태는 현재 탭 메모리에만 보관합니다.

카메라가 켜지면 신체 인식 전에도 중앙에 참고 목표 자세를 표시합니다. 이때는 **미정렬 가이드**라고 표시하며 점수를 계산하지 않습니다. 양어깨가 인식되면 몸에 맞춰 가이드를 정렬합니다. 모델 로딩·추론이 실패하면 연습만 중단하고 카메라와 참고 가이드는 유지합니다. 화면의 오류 문구를 확인하고 **자세 추적 다시 연결**을 누르면 카메라 권한을 다시 요청하지 않고 추적을 재시도합니다.

## 구현과 점수

- `src/tracker.js`: MediaPipe Pose Landmarker(33개 관절)와 Hand Landmarker(손별 21개 관절)를 Web Worker에서 실행합니다. GPU 초기화 실패 시 CPU로 재시도합니다. 매번 한 프레임만 추론하며 전송 속도는 최대 약 15 FPS입니다.
- `src/pose.js`: 영상 픽셀 좌표에서 양어깨 중점·너비·기울기를 이용해 신체 좌표계를 구성합니다. 골반이 보이면 몸통 방향을 참고하고, 보이지 않으면 화면 아래를 몸통 방향으로 사용합니다. 목표 자세를 이 좌표계에 매 프레임 정렬합니다. 팔 길이는 어깨 너비 기준의 기본 비율을 사용합니다.
- 팔 점수: 팔꿈치/손목 4개 위치의 평균 오차를 어깨 너비로 정규화한 뒤 `100 × exp(-3.5 × 평균오차)`로 변환합니다.
- 손 점수: 검지~소지의 관절 경로 길이 대비 손끝 직선거리로 펼침 정도를 비교합니다. 양손은 손목 위치로 대응시킵니다. 엄지 모양, 손바닥 방향, 세밀한 제스처는 평가하지 않습니다.
- 종합 점수: 팔 75% + 손 25%. 주요 관절 신뢰도 0.65 미만, 양손 미검출, 오래된 추론 결과에서는 종합 점수와 유지시간 누적을 중단합니다.
- 캔버스와 영상에 동일한 contain 좌표 변환과 거울 변환을 사용합니다. 좌우 지시는 사용자의 해부학적 좌우 기준입니다.
- 정면 상체 연습을 위한 **2D 일치도**입니다. 체형별 팔 길이 차이가 점수에 영향을 줄 수 있으며 깊이 정확도, 전신 안무, 의료적 자세 정확성을 보장하지 않습니다.

## 개인정보와 네트워크

웹캠 영상은 브라우저 내부 Worker에만 전달하며 업로드·녹화·분석 서버를 사용하지 않습니다. 카메라 연결 시 jsDelivr에서 고정 버전 `@mediapipe/tasks-vision@0.10.22-rc.20250304` JS/WASM, Google Storage에서 float16 Pose Lite / Hand 모델을 다운로드합니다. 글꼴은 Google Fonts에서 로드하며 실패하면 시스템 글꼴을 사용합니다. 완전 오프라인 배포에는 해당 파일을 로컬로 호스팅해야 합니다.

## 검증

`npm test`는 정렬의 이동/회전/스케일 불변성, 자세 오차, 관절·손 누락, 펼침/주먹 구분, 지속시간 조건 및 영상 레터박스 변환을 검사합니다. 실제 RGB 웹캠 인식률과 프레임 속도는 사용자 기기에서 확인해야 합니다.

Playwright가 있는 개발 환경에서는 서버 실행 후 `node scripts/browser-smoke.cjs <Playwright 패키지 절대 경로>`로 Chrome 가상 카메라 검사를 실행할 수 있습니다. 기본 설치 Chrome을 사용하며, 필요하면 `CHROME_PATH` 환경 변수로 실행 파일을 지정하세요. 모델 로딩·추론, 데모 자동 전환, 일시 정지, 거울 모드, 종료 정리, 반응형 레이아웃 및 권한 거부 복구를 확인합니다. 스크린샷은 Git에서 제외되는 `.test-output/`에 저장됩니다.

API 참고: [Pose Landmarker Web](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js), [Hand Landmarker Web](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js).

`node scripts/browser-regressions.cjs <Playwright 패키지 절대 경로>`는 공개 인물 사진을 카메라 스트림에 넣고 실제 MediaPipe 추론·목표 오버레이·연습 시작을 검사합니다. 별도로 골반 미검출과 추적 오류를 주입해 영상 유지 및 재연결을 검사합니다. `SITE_URL`을 설정하면 배포 사이트에서도 실행할 수 있습니다. 정지 사진 검사와 오류 주입 검사는 실제 사람이 움직이는 RGB 웹캠 환경의 인식률 검증을 대신하지 않습니다.
